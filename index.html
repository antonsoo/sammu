    03 / Read the evidenceText, reconstruction, realization

    A surviving instruction is not the same
    as a complete reconstruction.

    Two Old Babylonian manuscripts from Ur preserve parts of a tuning text. Later witnesses supply named string pairs. Their combination lets scholars reconstruct a procedure; it does not supply an ancient recording, a measured instrument, or exact pitch ratios.

    The first three loosening cases show how preservation varies. These are our summaries of the published translation. In an edition, ⟨ ⟩ marks a supplied omission; [ ] marks restoration across damage.

    Read a little Akkadian

    Normalized romanization, not a cuneiform transcription or a claim about exact ancient pronunciation. š is conventionally “sh”; ḫ is a velar fricative; marks over vowels indicate length or contraction.

    What this audible model assumes

    String numbers describe positions. In this realization, strings 1–7 descend in pitch. A pair three string-steps apart is set to 4/3; one four steps apart is set to 3/2. The six clear pairs fix all seven pitches relative to the initial first string. The remaining pair is left unclear.

    Retuning solves that unclear pair while holding its other string fixed. It changes only the selected string and its companion, when present. There is no hidden rescaling when the tuning name changes. Exact fractions remain exact; hertz and cents are modern display units.

    The decaying sound combines six sine partials. The steady sound uses one. Neither reproduces an excavated instrument. Hearing roughness depends on spectrum, register, listening conditions and the listener; the source word zakû is not a universal pleasantness score.
